## Goal

Give the simulation its single authoritative, fixed-extent, integer tile grid: `MapGrid` storage,
`MapCell` flags and costs, lane waypoint definitions, integer cell↔world conversions in Q16.16,
passability queries, deterministic neighbor ordering, and a little-endian `.mapdesc` codec so a map
can be authored offline, loaded by stable `AssetId`, hashed into the canonical state, and replayed.
No rendering, no flow fields, no units move yet.

## Contract this lane implements

```text
MapGrid  { uint32 schema_version; AssetId map_id; uint16 width_cells; uint16 height_cells;
           int32 cell_size_q16; uint32 cell_count; MapCell cells[cell_count];   // row-major, y then x
           uint16 lane_def_count; LaneDef lanes[lane_def_count]; }
MapCell  { uint8 flags; uint8 movement_cost; int16 height_cell; }             // flags: walkable, blocked, lane, spawn, objective
LaneDef  { uint8 lane_id; uint8 waypoint_count; uint16 wave_interval_ticks; uint32 first_wave_tick;
           AssetId creep_archetype_id; uint16 waypoints[waypoint_count]; }     // waypoint = cell index
```

Storage inside `SimWorld` is SoA (`flags[]`, `movement_cost[]`, `height_cell[]`) in a caller-owned
arena, fixed capacity from `sim_config.h`. Conversions: `cell_index = y * width + x`;
`world_q16 = cell * cell_size_q16 + cell_size_q16 / 2`; `cell = world_q16 / cell_size_q16` with
floor semantics and explicit out-of-bounds status. Neighbor order is fixed: N, E, S, W, then NE, SE,
SW, NW; diagonal moves require both orthogonal neighbors walkable.

## Acceptance

- Adds executable tests for proto-design §7.2 items 1 (identical streams → identical hash), 2
  (malformed map rejects without mutation), 9 (codec rejects at first invalid boundary).
- Oracle final/stream hashes stay `0x637628abff59c823` / `0x6f381609f7e59f0c` **until S5**; S5's
  deliberate `SIM_LOGIC_HASH` bump is the only permitted change and must be recorded.
- `eng_sim` link graph unchanged (`core + math + serialize`); `map.cpp` passes the sim compiler
  policy and isolation self-tests.
- No Vulkan smoke required (no renderer change); state that explicitly in the slate.
