## The shape of the session

1. **Iteration order became a literal rule, not a comment.** Each `ComponentPool` owns an
   arena-backed ordered `EntityId` cache, invalidated on membership change and rebuilt by a
   validated ascending sparse-index scan, atomically. Order-sensitive systems iterate the
   cache; commutative systems (pure integration) may iterate dense. The rule M3.2's design
   review demanded is now enforced by data structure, not discipline.
2. **Events went phase-buffered with an experiment seam.** Append/publish/read/consume are
   explicit phases; invalid events, overflow, and unread-phase publication are
   mutation-free. Damage publishes and resolves in the *same* tick to preserve M3.1
   behavior — the two-phase API deliberately scaffolds a future next-tick experiment by
   moving only publication.
3. **One literal schedule.** `sys_apply_commands` → `sys_movement` → `sys_combat_resolve` →
   `sys_cooldown_tick` → `sys_rng_advance` → `sys_flush_destroy` are plain prefixed free
   functions called in source-visible order. The simplest thing that can't lie about order.

---

## Cross-cutting decisions

- **Queue overflow is preflighted before any command mutation** — the deterministic world's
  "reject without mutation" rule again, at the input boundary.
- **Logic hash moved deliberately** to `0xab96814425ba80a4`; canonical state covers logical
  event phases while excluding physical buffers, query caches, pointers, padding, unused
  capacity, and dense order.
- **Timing-policy tradeoffs were written down, not decided:** stale-target policy and the
  extra latency of next-tick damage remain explicit, named tradeoffs to measure — the M3.3
  queue picks them up.

## Lessons for future sessions

- **Same-tick vs next-tick damage must be measured before changing policy** — the queue
  seam exists precisely so that experiment doesn't touch the schedule.
- **The merge gate here was owner review, and the branch discipline held:** M3.3 was
  explicitly forbidden from stacking on the M3.2 branch; the handoff recorded it.
- **Deferred:** M3.3 (fixed-tick loop + present boundary, on its own slate), M3.4 (flag
  pinning/isolation), Vulkan SDK in CI.
