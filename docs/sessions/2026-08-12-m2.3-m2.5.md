## The shape of the session

1. **The pickup slate carried the whole remaining phase.** M2.3–M2.5 ran as one execution
   surface with an explicit fence (no sim, no assets, no gameplay). The owner gate (S6)
   was run live on the RTX 4070 Ti — the interactive DoD that scripted runs can't prove.
2. **The seam audit was a structural proof, not a style pass:** grep confirmed no Vulkan
   identifier or include anywhere above the seam — the sandbox, tests, and public renderer
   headers are Vulkan-free. The compiler enforces what the architecture promises.
3. **Deterministic batching became real:** `DrawItem`s sort by (pipeline, material, mesh),
   model matrices pack into a per-frame storage-buffer instance stream, and a 4-byte
   `instance_base` push constant selects each coalesced batch — 500 cubes, one draw.

---

## Cross-cutting decisions

- **The provisional single-texture/draw API was killed in M2.5.** `renderer_types.h` is now
  the Vulkan-free authority for typed descriptors, `FrameView`, `DrawItem`, and stats;
  destroy calls retire handles for at least two frames (`frames_until_free`) — the
  asset hot-reload path M4.4 needs is already baked into the signatures.
- **`eng_render_common` + `eng_render` + always-built `eng_render_null`** made the seam
  testable on a Vulkan machine and headless everywhere else; `sandbox_null` runs a blank
  window with valid handles.
- **Debug draw allocates one fixed vertex block from the frame arena** — no per-call
  allocation, and it can never feed back into the sim.

## Lessons for future sessions

- **The owner-interactive gate is a real verification lane.** Scripted runs proved the
  paths; the live display run proved the event log (resize/minimize/focus/F1) and
  validation silence on hardware. Budget for it; don't fake it with scripts.
- **Typed-handle + deferred-destroy is the API shape Phase 4 consumes.** M2.5 settled the
  asset↔renderer upload seam one phase early, which is exactly when it should be settled.
- **Deferred (still):** Vulkan SDK in hosted CI (owner-gated), interactive DoD for
  M2.0–M2.2 (covered by S6), `plat_mem_*` TU split, clang-cl/UBSan run.
