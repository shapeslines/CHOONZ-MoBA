## The shape of the session

1. **Seeing was the blocker, and it was solved first.** The sandbox window runs in an
   isolated window station, so `FindWindow`/`PrintWindow` can't capture it — the agent
   could not *see* the renderer's output. The in-session answer was `tools/visualize`
   (headless BMP dumps of the fixed-point math) plus the CI JUnit report; the readback
   screenshot that finally made the renderer visible landed in M2.1. Lesson: **verification
   capability is a feature; build it before you need it.**
2. **Dual backend so CI stays green without an SDK.** The runner has no Vulkan SDK, so
   `eng_render` compiles the real backend when `find_package(Vulkan)` finds headers and a
   null backend otherwise. This is the early form of the M2.5 null backend and the reason
   the `find_package(Vulkan) → REQUIRED` flip is a separate, owner-gated step.
3. **A latent `.gitignore` bug fixed pre-emptively:** inline comments made `*.spv`/
   `baked/`/`*.mba`/`*.pak` match nothing — would have bitten in Phase 2/4.

## Cross-cutting decisions

- **Hand-loaded loader (ADR-0004) was exercised for real.** Every call routes through the
  renderer's own dispatch table in three tiers (global/instance/device); `vulkan-1.lib` is
  never linked. This was the load-bearing bring-up risk of the phase, and it held.
- **The acquire-semaphore hazard was handled by writing the recipe down:** `OUT_OF_DATE`
  does not signal the semaphore (bail and recreate); `SUBOPTIMAL` does (proceed through
  submit/present, then recreate). Conflating the two leaks a signaled semaphore — the exact
  class of bug M2.0 exists to teach.
- **`VULKAN_SDK` is shell-session-dependent** — a session started before the SDK install
  doesn't see the env var; the pre-push gate and CI therefore build null unless it's set.

## Lessons for future sessions

- **Visualizing tests is worth a dedicated tool.** `fix_trig_error.bmp` made a numeric
  tolerance tangible; the readback screenshot (M2.1) later made the whole renderer
  verifiable by an agent. Agent-visible evidence > logs.
- **`.bat` files are ASCII-only**; a stray em-dash breaks `cmd`'s parser (surfaced again
  in Session 02's gate). Use `git commit -F`/`gh --body-file`, never PowerShell here-strings.
- **Deferred for later sessions:** interactive M2.0 DoD (needs a display), Vulkan SDK in CI,
  in-process readback (done in M2.1), `plat_mem_*` split from the Win32 window TU.
